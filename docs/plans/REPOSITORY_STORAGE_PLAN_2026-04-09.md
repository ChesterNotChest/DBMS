这是一个DBMS系统的仓库。

此文件的需求[已完成]。

1. 理解我们将使用的文件存储设计思路：
   数据库=目录；表=一个文件
2. 将每个表的具体操作（增删改查）抽象到repos里，分别放到database_repo.cpp，meta_repo.cpp，table_repo.cpp，sort_index_repo.cpp。可能需要的类定义、常量定义、库引用放到repo.h
3. database_repo.cpp 写入数据库管理文件root.dbf。用来存有什么数据库，记录数据库名称，便于根据数据库名直接访问对应的元数据文件/data/[数据库名].meta。
4. meta_repo.cpp 写入元数据文件[数据库名].meta。用来展示存有什么表，记录表名称，便于根据表名直接访问对应的表文件：/data/[数据库名]/[表名].dat。
5. table_repo.cpp 写入表文件[表名].dat。用来展示表里存了什么数据。存什么由用户自己定。
3-4-5附加. .dbf、.meta和.dat本质存法一致，都是存二维表。唯一的区别是后缀名。
6. sort_index_repo.cpp 写入排序索引文件```[源表名]__[索引名].idx```。用来展示某个表对应的排序索引数据，记录索引名称和索引内容，便于根据数据库名、表名和索引名直接访问对应的索引文件：/data/[数据库名]/indexes/[源表名]__[索引名].idx。(TODO备忘。下一步需要为它独立写一个util方法)
